# Guide du caissier — Nguon POS

Ce guide tient en une page : comment ouvrir sa caisse, vendre, contrôler les entrées et réagir aux problèmes courants.

## 1. Ouvrir la caisse

1. Allumez l'ordinateur et ouvrez **Nguon POS** (icône sur le bureau).
2. Saisissez votre **nom d'utilisateur** et votre **mot de passe**, puis **Se connecter**.
   - La toute première fois sur une caisse, il faut internet. Ensuite, la connexion marche aussi sans internet.
   - Si le message dit « Ce compte est affecté à une autre porte », vous n'êtes pas à la bonne caisse.
3. En haut de l'écran, vérifiez :
   - le **nom de la porte** (à gauche) ;
   - **En ligne** (vert) ou **Hors ligne** (rouge) : les deux permettent de vendre ;
   - l'imprimante a du papier.

## 2. Vendre

1. Touchez le billet demandé. Chaque toucher ajoute un billet ; utilisez **+** et **−** dans le **Panier** pour corriger.
2. Choisissez le paiement : **Espèces**, **Mobile Money**, **Carte bancaire** ou **Autre**.
3. En espèces, saisissez le **Montant reçu** : la **Monnaie à rendre** s'affiche.
4. Appuyez sur **Encaisser**.
5. Imprimez :
   - **Imprimer le billet** (ou **Imprimer les N billets**) : les billets à remettre au client ;
   - **Imprimer le reçu** : apparaît quand la vente compte plusieurs billets.
6. **Nouvelle vente** (ou la touche **Entrée**) pour le client suivant.

> La vente est enregistrée **avant** l'impression. Si l'imprimante bloque, rien n'est perdu : voir « Réimprimer ».

## 3. Réimprimer une vente

Imprimante bloquée, plus de papier, billet perdu par le client :

1. Onglet **Mes ventes** (en haut).
2. **Aujourd'hui** ou **Toutes** ; cherchez la référence si besoin.
3. **Réimprimer** sur la vente, puis le bouton d'impression voulu.
4. **Retour à mes ventes** pour revenir à la liste.

## 4. Contrôler les entrées (scanner)

Onglet **Scanner**, puis présentez le QR code du billet au lecteur.

| L'écran affiche | Ce qu'il faut faire |
|---|---|
| **Billet valide** (vert) | Laisser entrer. |
| **Billet déjà utilisé** | Refuser : ce billet est déjà entré. |
| **Mauvaise porte** | Orienter la personne vers la porte indiquée sur son billet. |
| **Vente annulée** | Refuser : la vente a été annulée par l'administration. |
| **Billet invalide** | Refuser : ce n'est pas un vrai billet Nguon. |
| **Non reconnu sur cet appareil** | Demander le reçu et appeler votre coordinateur. |

## 5. Sans internet

- **Continuez à vendre et à scanner normalement.** Tout est enregistré sur la caisse.
- Un **chiffre sur fond jaune** sur le bouton de synchronisation (deux flèches en cercle) indique les ventes pas encore envoyées au serveur. Elles partent toutes seules quand internet revient.
- Le badge **caisses voisines** indique que les caisses de votre porte se parlent par le réseau local : un billet vendu à côté est reconnu chez vous, même sans internet.
- Éteindre ou redémarrer l'ordinateur ne fait rien perdre. Par contre, **ne désinstallez jamais l'application** pour « réparer » : les ventes pas encore envoyées sont sur cet ordinateur.

## 6. Fin de service

1. Si possible, attendez que le chiffre jaune du bouton de synchronisation disparaisse (toutes les ventes envoyées).
2. Cliquez sur l'icône **Se déconnecter** (tout à droite).
3. Laissez l'ordinateur allumé et connecté si votre coordinateur le demande.

## 7. En cas de problème

| Problème | Solution |
|---|---|
| L'impression ne sort pas | Bouton **imprimante** en haut : vérifiez l'**Imprimante** choisie et la **Largeur du papier**. La vente est conservée : **Mes ventes → Réimprimer**. |
| Le texte du billet est coupé d'un côté | Même bouton : **Décalage horizontal (mm)**, positif vers la droite, négatif vers la gauche. |
| « Nouvelle version installée — redémarrer » | Terminez la vente en cours, puis cliquez : la caisse redémarre en quelques secondes. |
| « Le service local de la caisse ne répond pas » | Redémarrez l'ordinateur. |
| Autre souci | Bouton **Support** (bouée, en haut, ou sous le bouton Se connecter) → **Enregistrer le diagnostic** → envoyez le fichier à votre coordinateur. Il ne contient aucun mot de passe. |
